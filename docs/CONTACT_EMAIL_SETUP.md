# Contact form: Zoho Mail

The contact form posts to `/api/contact`, which sends project briefs and optional
attachments through Zoho SMTP. Messages are sent from and delivered to
`hello@mzfortech.com`. The visitor's email is set as Reply-To, so replying to a
brief reaches the visitor without impersonating their address as the sender.

## Activate delivery

1. Set `ZOHO_SMTP_PASSWORD` in the ignored `.env.local` file to the mailbox's
   SMTP password. With two-factor authentication enabled, generate a Zoho
   application-specific password. Never commit passwords or share them in chat.
2. The supplied account configuration uses `smtp.zoho.com`, port `465` (SSL).
   Confirm the host in Zoho Mail's Server Configuration Details for this mailbox.
   Paid organization accounts may require `smtppro.zoho.com`; other data centers
   may use different hosts. Port `587` is also supported with mandatory STARTTLS.
3. In your hosting provider, add all six variables from `.env.example` as
   server-side environment variables, including the real password. Do not prefix
   them with `NEXT_PUBLIC_`. Local configuration does not configure production.
4. Restart the local server or redeploy production after setting the variables.
5. Submit a short brief through `/contact`. Confirm it arrives in the mailbox
   and that Reply addresses the visitor. Also check an attachment if needed.

Until the password is configured, the endpoint returns a setup message (503),
not a successful delivery confirmation. SMTP delivery failures return 502.

## Domain DNS

These records are managed at your DNS provider, not in this repository. Confirm
the account-specific records in the Zoho admin console before making changes.

| Type | Host | Priority | Value |
| --- | --- | --- | --- |
| MX | @ | 10 | mx.zoho.com |
| MX | @ | 20 | mx2.zoho.com |
| MX | @ | 50 | mx3.zoho.com |
| TXT | @ | — | v=spf1 include:zohomail.com ~all |

Maintain only one SPF record: if other services already send email for this
domain, merge the Zoho include into the existing SPF policy rather than adding
a second SPF record. Configure DKIM using the selector and key generated by
Zoho, then verify it in the admin console. IMAP and POP settings are not needed
by the contact form.

Reference: https://www.zoho.com/mail/help/zoho-smtp.html
