# Model Zero auth.md

This page is for agents discovering Model Zero's public website and research.
Public pages, discovery documents, and the read-only
[research endpoint](https://www.mzfortech.com/api-docs.md) require no authentication.
Content usage preferences are declared in
[robots.txt](https://www.mzfortech.com/robots.txt).

Agent registration and credential provisioning are not supported. There are
no registration, claim, revocation, token, or authorization endpoints, and no
OAuth scopes or supported agent identity methods. Do not send access tokens,
identity assertions, or secrets to the contact form.

For an integration request, contact hello@mzfortech.com. This is a human contact
address, not an automated registration service.
